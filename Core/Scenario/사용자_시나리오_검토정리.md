## 1. 제품 개요 / 핵심 결론

싱크대용 가정용 음식물 처리기로, **헹굼(모음) → 건조·분쇄·수증기배출·처리물배출(동작) → 자가세척 → 살균세척**의 자동 공정을 수행한다. 설계 핵심은 두 가지다.

1. **처리 자동화** — 사용자 위치 선택(마개 스위치)에 따라 단계별 공정 자동 진행.
2. **불법 배출 방지 (회로 락)** — 음식물이 처리 공정에 들어간 뒤 **바로 생분쇄되어 하수구로 배출되지 못하도록** 차단. 소프트웨어 명령만이 아니라 **히터 가동(건조)·온도 조건·리미트 스위치·레치 릴레이·수거통 감지**를 함께 사용해 분쇄·배출을 **단계적으로만 허용**한다.

> 핵심 명제: "히터 가동(건조)이 물리적으로 증명되지 않으면 분쇄·배수 모터로 가는 동력이 원천 차단된다." (부록 PPT 1p 회로 로직도)

## 3. 불법 배출 방지 회로 락 (Fail-safe 핵심)

소프트웨어로 우회 불가능하도록 **온도센서·리미트 스위치·레치 릴레이**를 물리 회로로 결합한다. (부록 PPT 1p)

### 3.1 온도 조건 게이팅

| 조건 | 의미 | 프로그램 반영 방향 |
|------|------|--------------------|
| **투입구 마개 개방** | 처리 중 추가 투입/비정상 개방 | 즉시 모터 차단, 추가 투입 금지 안내, 안전 상태 전환 |
| **60도 (NC 바이메탈)** | 히터 가동 후 **급수 금지 구간** 진입 | 급수용 솔레노이드 밸브 전원 차단 |
| **80도 (NO 바이메탈)** | **분쇄모터 동작 허용** 기준 | 조건 만족 전 분쇄모터 구동 금지(릴레이 ON) |
| **100도** | 수증기 발생 기준 | 수증기 배출 관로·팬·외부 공기 유입부 제어 |
| **190~195도** | 건조 말기 히터 온도 유지 | **195도 이상 OFF, 190도 복귀 시 ON 반복** |
| **210도 안전 차단** | 과열 안전 기준(바이메탈) | 히터 강제 차단 |

> 이전 정리본의 "50도 기준"은 **폐기**. 현행 회로도는 **60도 NC(급수 차단) + 80도 NO(분쇄 허용)** 로 분리됨.
> ✅ 안전 차단 온도 **210도 확정** (PPT 1p "2010도"는 오기).

### 3.2 기억 레치 릴레이 (SET/RESET) & 딜레이 타이머

- **레치 릴레이**: 건조·배출 완료 → **배출부 문이 열리고 약 2분 후 닫히면** 🔲(닫힘 시간 2분/60초 혼용 §9-2) 리미트 스위치 신호가 레치 릴레이를 동작시켜, 배수부 모터에 전원 인가 → **배수부를 완전히 열어 놓고 정지**. 이 지점까지가 "음식물 처리 완료". 강제 전원 리셋·시간차 배출 등 비정상 조작으로 우회 불가.
- **딜레이 2분 타이머**: 투입구 마개(문)가 열리면 **2분 카운터 시작 → 모터 전원 차단 → 2분 후 재연결**.
- **처리 완료 기준의 의의**: 배수부를 완전 개방한 채 정지해야, 소비자가 이후 언제든 설거지하며 물을 버릴 때 싱크대 배수가 가능하다.

### 4.3 배출 전 수거통 확인

| 확인 항목 | 정상 조건 | 비정상 처리 |
|-----------|-----------|-------------|
| 수거통 유무 | 홀센서 감지 | 수거통 장착 안내 후 대기 |
| 처리 횟수 | 6회 미만 또는 배출 가능 상태 | 6회 이상이면 수거통 비움 안내 |
| 분말 높이 | 높이 센서 정상값 | 센서값 불안정 시 처리 횟수 기준으로 판단 |
| 사용자 미조치 | 안내 후 수거통 비움 | **10초 간격 5회 안내 후 교반모터 정지 및 대기** |
| 재장착 | 수거통 재삽입 홀센서 감지 | 재확인 후 이상 없으면 배출 진행 |

> 대기 중 사용자가 무의식적으로 투입구 마개를 열면 → 안내 멘트 후 마개를 원 상태 "동작" 위치로 복귀 안내(2회) → 재삽입(홀센서) 감지 시 배출 절차 재개. 배출부 문 열리고 2분 후 닫힘과 동시에 리셋(초기화) → 3단계로 이어짐.

### 4.4 자가세척 (3단계)

- **음식물이 없는 상태**에서 배수구 닫고 **1단계 헹굼 세척과 동일 동작 기본 1회** 수행 후 종료.
- 실행 조건: **5번째 처리 후 자동 실행**. (6번째 처리 후에는 자가세척 대신 살균세척 안내로 이어짐)

### 4.5 살균세척 (4단계)

> **음식물 처리 6회째가 끝나면** 안내 멘트를 **5초 간격 3회** 송출. 신호 없으면 대기.
> 투입구 마개는 6회째 처리 위치를 그대로 유지.

1. 소비자가 본체 **"세척 버튼" 선택** → 배수부 닫고 급수 솔레노이드 밸브 열어 급수 → 수위센서 감지 후 **2초 더 급수** (수위센서 에러 시 예: 15초 급수 타임 후 차단).
2. **건조 히터 ON** → 교반가이드 **30RPM**, 정회전 3초→1초 멈춤 / 역회전 3초→1초 멈춤(분쇄와 동시 반대 회전)을 설정 시간까지 반복.
3. 히터 온도 **60도 이상** → 분쇄모터 **1500RPM**, 정회전 3초→1초 멈춤 / 역회전 3초→1초 멈춤(교반과 동시 반대 회전)을 설정 시간까지 반복.
4. 내부 온도 **100도 감지 후 5분간** 물 끓는 상태로 살균 세척 지속 → 히터·분쇄모터 OFF.
5. 교반가이드만 원래대로 회전하며 **배수구를 열어 30초간 배수** → 살균세척 종료 → 모든 기능 리셋, 초기 대기 상태 복귀.

> ★변경: 살균 물은 **배수구로 배수**(30초). 이전 "수거통으로 버림" 흐름은 폐기 → 화상/누수 안전 이슈 해소.

### 4.6 배수 기능 (설거지 배수 보조 — 처리 공정 아님)

설거지 중 물 배수가 잘 안 될 때 쓰는 **별도 보조 기능**.

| 순서 | 동작 |
|------|------|
| 1 | 투입구 마개를 열어 놓고 마개를 '배수' 위치에 둔다 |
| 2 | 약 3초 후 교반가이드가 저속 **약 15RPM**으로 회전 |
| 3 | 정회전 5초 → 5초 정지, 역회전 5초 → 5초 정지 반복 |
| 4 | 위 동작을 약 3분간 반복 |
| 5 | 3분이 되기 전에 뚜껑을 닫으면 배수 기능 정지 |

### 4.7 찰음 / 강한음식 모드

- 밥 과다 투입, 떡 과다 투입, 게껍데기 등 **강한 음식** 대응 보정 프로그램.
- 기존 프로그램 대비 교반가이드·분쇄모터의 **회전 방향·속도가 조금씩 다를 수 있음**.
- **1차 기본 프로그램 완성·테스트 후 업그레이드 예정** (세부 파라미터 미확정).

## 5. 안전 / 예외 처리

### 5.1 추가 투입 금지 · 비상 정지

- **처리 중 추가 투입 금지**: 동작 기능 시작 후 추가 음식물 투입 불가(모음 기능이 있으므로 중간 투입 미허용이 안전).
- **투입구 개방 시**: 처리 중 마개가 열리면 **즉시 모터류 정지 + 추가 투입 불가 안내** 송출.
- **정지 버튼 3초**: 멤브레인 정지 버튼 3초 이상 → **완전 정지**(검토 항목).
- **완전 정지 시**: 히터·분쇄모터·교반모터·배수모터·배출모터·밸브·팬 OFF. **고온 상태에서는 안전 식힘 조건 별도 적용.**

### 5.2 모터 부하량 체크 및 걸림 해소 (신규 §4.6)

> 부하량 최종 수치는 문서에서 단정하지 않음 — **1차 PCB 샘플 테스트 후 실제 측정값 기준**. 변수/설정값으로 분리 구현.

| 대상 모터 | 부하 발생 시 동작 |
|-----------|-------------------|
| 교반가이드 모터 | 즉시 반대 방향 회전. 잔여 걸림 시 부하 재체크 → **방향 전환 최소 4회** 시도 → 미해소 시 정지·에러 멘트 |
| 분쇄모터 | 회전 방향 반대로 걸림 해소 시도. **최소 4회** 방향 전환 후에도 부하 지속 시 정지·에러 멘트 |
| 배수부 모터 | 개폐 중 과부하 감지 시 즉시 스톱 → 위치 확인·에러 멘트 |
| 배출부 모터 | 문 개폐 중 과부하 감지 시 즉시 스톱 → 문 위치·수거통 상태 확인 안내 |
| 설치용 상승/하강 모터 | 높이 조정 중 과부하 감지 시 즉시 스톱 → 상하 스톱 센서·걸림 확인 안내 |

## 8. 외주 개발사 확인 필요 사항 (기획서 §7)

### 우선순위 상
1. **레치 릴레이 SET/RESET 조건과 리미트 스위치 접점 구성** — 불법 배출 방지 회로 락의 핵심 조건.
2. **60·80·100·190·195·210도 센서 위치와 기준값** — 온도 위치가 다르면 프로그램 조건이 달라짐.
3. **처리 중 투입구 개방 시 히터·팬의 안전 처리** — 사용자 안전 및 냄새/수증기 배출.
4. **배출부 문 닫힘 후 배수부를 완전히 열고 정지하는 완료 시퀀스** — 설거지 배수가 항상 가능해야 함.
5. **교반가이드·분쇄모터 부하량 감지 및 최소 4회 방향전환 조건** — 떡·게껍데기 걸림 대응.

### 우선순위 중
6. **배출문 닫힘 시간 "2분 vs 60초" 표기 차이** — 기준값 혼선 제거.
7. **히터 용량 250W/100W 최종 PCB 기준 및 210도 바이메탈·안전센서 4개·온도센서 2개** 표기 확인.
8. **각 모터별 부하량 기준값 및 분쇄모터 RPM 1000/1500/2000 조건**의 실제 부하 테스트.
9. **급수 타임아웃 기본값** — 수위센서 고장 시 누수 방지.
10. **정지 버튼 3초 완전 정지 후 재시작 정책** — 중간 정지 후 재가동 리스크 방지.

## 9. 검토 의견 — 추가 확인·명확화 필요 (개발 관점)

1. 🔲 **[다음 확인 예정] 모음 완료 "21분 30초" vs 단일 사이클(약 3분 30초)** — 반복 횟수/총 시간 정의 필요(§2, §4.1). 전체 동작 구조표와 4.1 순서표의 시간 정합성이 맞지 않음. **사용자 확인 대기 중.**
2. 🔲 **[다음 확인 예정] 배출문 닫힘 시간 "2분 vs 60초" 표기 차이** — 4.2 배출 구간 및 회로 락 완료 시퀀스의 기준 시간. 문서 내 혼용(기획서 §7 "중" 항목에도 명시). **사용자 확인 대기 중.**
3. ✅ **분쇄모터 출력** — BLDC **300W 확정** (200W 표기 폐기).
4. ✅ **안전 차단 온도** — **210도 확정** ("2010도"는 오기).
5. **RPM/회전시간/정·역 방향** — 대부분 "가변/검토"로만 명시(부하 크면 30RPM 등). 양산 기본값 미확정 → 변수·설정값 분리 구현 전제.
6. **음성 안내 미응답 후 복구 절차** — "10분 후 교반 정지·대기" 이후 재개 조건(재장착 감지 외) 명확화.
7. **투입구 오조작 상태머신** — 대기/처리 중 마개 개방 → 비상음·복귀 안내(2회)·재삽입 감지 → 절차 재개의 상태 전이 정의.
8. **하드웨어 차단 vs MCU 제어 책임 분담** — 바이메탈·레치 릴레이(HW)와 MCU(SW)의 경계. **MCU가 정지해도 HW 차단이 유지되는지** 검증(회로 락 실제 접점 = PCB 락 조건 일치 확인).
9. **멘트 문구·에러 멘트** — 별도 문서로 제공 예정. 변수화하여 후속 반영 가능하게 분리.
