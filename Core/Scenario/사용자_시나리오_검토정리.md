## 1. 제품 개요

가정용 음식물 처리기로, **음식물을 세척·건조·분쇄·배출**하는 4단계 자동 공정을 수행한다. 핵심 설계 목표는 두 가지다.

1. **처리 자동화** — 모음(세척) → 동작(건조·분쇄·배출) → 자가세척 → 살균세척
2. **불법 배출 방지 (Fail-safe)** — 생분쇄물이 하수구로 그대로 빠져나가지 못하도록, **소프트웨어가 아닌 물리 회로(바이메탈·래칭 릴레이)로** 원천 차단. "히터 가동(건조)이 물리적으로 증명되지 않으면 분쇄·배수 모터로 가는 동력이 원천 차단된다"는 것이 설계의 골자다.

## 4. 단계별 시나리오 (핵심)

> 전체 공정: **1단계(모음/세척) → 2단계(동작: 건조-분쇄-배출) → 3단계(자가세척) → 4단계(살균세척)**
> 1단계는 "모음" 1회 / "동작"·"강음" 시 기본 2회(선택에 따라 3~5회) 반복.

### 4.1 1단계 — 모음 (헹굼 세척, 염분 제거)

음식물이 담긴 상태에서 물로 헹궈 염분을 제거하는 단계.

1. **배수모터 동작** — 배수문 닫음 (배수구 차단)
2. **급수밸브 동작** — 급수 시작 → 수위센서 감지 시 정지 (센서 감지 후 수 초 뒤 정지, 센서 에러 시 OFF)
3. **수위센서 감지** — 급수 완료
4. **교반모터 동작(BLDC)** — 정·역 회전 반복 (RPM 40 × 정회전 5초 / 역회전 5초, **2분 30초간** 회전)
5. **배수모터 동작** — 배수 시작 → 종료 (교반 시작 후 약 2분 30초 뒤 배수 시작, ~20초 후 배수문 닫음)
6. **기본 1회 반복 후 종료**

### 4.2 2단계 — 동작 (건조 → 분쇄 → 배출) ★핵심

> **선행 조건: 염분 제거를 위해 1단계(헹굼)를 반드시 2회 수행한 뒤 진입.**

1. **배수모터 동작** — 배수문 닫음
2. **히터 전원 ON (220V)** — 온도 상승 시작. 리미트 스위치 닫힘과 동시에 220V 공급.
   - **온도 상승 프로파일 (시간대별 써미스터 제어, ON/OFF 조절)**
     - 220V ON ~ **25분 이내 130도**
     - ~ **60분 이내 150도**
     - ~ **90분 이내 170도**
     - ~ **120분 이내 195도**
   - 안전: **210도 이상 시 바이메탈 B,OFF(2개)로 차단**, 써미스터로 200도 초과 방지
3. **교반모터 동작(BLDC)** — 정·역 회전. (배수 타임 3분 종료 후) 정회전 5초 → 2초 쉬고 → 역회전 5초 반복. (RPB 23×120분, 정역회전 타임·RPM 가변)
4. **분쇄모터 동작(BLDC 200W)** — **온도 50도 이상**부터 동작 가능(그 전엔 바이메탈+온도로 잠금).
   - 초기: 교반과 같은 방향으로 2초(최고 순간 파워, RPM 1500) 회전 후 2초 쉬고, 역회전. 3분간 반복 후 RPM 600으로 낮춰 3초 정·역 반복.
   - **80도 이후**: 1000RPM으로 교반과 같은 방향 3초 회전, 2초 정지 → 15분 반복. 이후 RPM 1500 순간 1.5초 회전, 2초 정지를 15분간 반복. (죽 → 밀가루 반죽 수준까지 분쇄)
5. **수증기 온도센서 동작** — 내부 온도 **100도(100.5도)** 도달 시:
   - 계폐부(관로) 열고 **에어공급 스테핑 모터 + 방수팬** 동작 → 수증기·냄새 배출
   - **80도로 떨어질 때까지** 배출 후, 에어공급부·계폐부 닫고 팬 정지 (101도 될 때까지) → 공정 반복
   - (문 열면 온도 하강 → 그 기준으로 닫아 다시 수증기 모음. 반복하며 건조. **약 1시간 30분** 진행)
6. **건조·분쇄 타임(약 120분) 종료** → 히터 OFF, 교반만 같은 조건 정·역 회전하며 **10분 냉각**. 이후에도 교반은 배출 끝날 때까지 계속.
7. **배출부 모터 동작** — 처리물 배출 후 닫음
   - 배출 전 체크: **수거통 유무(홀센서) / 처리 횟수 / 음식물 쌓인 높이(근접센서)**
   - 이상 없으면 배출. 높이센서 값 이상 시 → 음성 안내("수거통을 비운 다음 원위치 시켜 주세요")
   - 수거통이 차서 "비워 달라" 멘트(10초 간격 5회)에도 안 비우면 → 10분 후 교반모터 정지·대기
   - 배출부 문 열리고 **2분 후** 문 닫힘과 동시에 **리셋(초기화)** → 3단계로 이어짐
   - 배출부 모터: 전원 차단 후 타이머 경과 뒤 재인가 (2분 딜레이 타이머)

### 4.3 3단계 — 자가세척

- **음식물이 없는 상태**에서 진행, **1단계 "모음"과 동일한 동작**.
- 배수구 닫고 → 1단계 헹굼 세척 기능 기본 1회 수행 → 종료.

### 4.4 4단계 — 살균세척

> **음식물 처리 6회가 끝나면 7회째에 자동 진입.** 물을 끓이며 살균.

1. "음식물 처리 6회가 끝났습니다. 이어서 살균세척입니다. 수거통을 비우고 다시 삽입해 주세요" 음성을 **5초 간격 3회** 안내. 신호 없으면 무시하고 대기.
2. 수거통 재삽입 감지 → 배수구 문 닫음 → 급수 (수위센서 감지 후 3초 추가, 센서 에러 시 급수 타임 동시 체크로 정지)
3. **건조 히터 ON** → 교반 가이드 최고속 정회전 5초 / 1초 쉬고 역회전 5초 반복
4. 교반 회전 시작 후 **15분(50도 바이메탈 동작 전) 시점**에 배수부 문을 약 2초 열었다 닫아 물 약 30% 배수
5. 히터 온도 **50도 이상** → 분쇄모터 회전(교반과 역방향, 동일 타임 정·역)
6. 내부 온도 **100도 감지 후 10분간 끓임**(살균 세척 지속) → 히터 OFF, **20분 냉각**
7. 냉각 20분 후: 분쇄 정지, 교반만 계속 회전하며 수거통 유무·가루 높이 체크 → 배출부 모터로 문 1/3만 열어 물 배출(문 세척 목적, 2분간) → 2분 후 교반 정지, 배출부 문 닫음
8. **모든 기능 리셋 → 초기 대기 상태 복귀**

> **살균세척 물 배출**: 배수로 흘려보내지 않고 **수거통으로 버림**. "수거통에 이물질을 버려주세요"를 5초 단위 안내. 사용자 조작 없으면 물을 그대로 보관. 이후 뚜껑을 열면 "물이 있습니다, 수거통을 비워주세요" 안내.

## 5. 불법 배출 방지 로직 (Fail-safe 핵심)

소프트웨어로 우회 불가능하도록 **물리 회로**로 구성. (로직도 1p 기준)

- **원리**: 히터 가동(건조)이 물리적으로 증명되지 않으면 분쇄·배수 모터 동력이 원천 차단.
- **바이메탈 게이팅**
  - 50도 미만: 분쇄 BLDC / 배수 모터 동력 차단 (건조 미증명 상태)
  - **50도 도달(NC 바이메탈)**: 배수모터 차단 해제, 급수밸브 차단, 기억 래칭 릴레이에 초기 신호
  - **50도 초과(NO)**: 분쇄 BLDC 동작 가능
  - **200~210도**: 과열 차단(안전 바이메탈)
- **기억 래칭 릴레이(SET/RESET)**
  - 건조·배출 완료 → **배출부 문이 열리고 2분 후 닫히면** 리미트 스위치 신호가 래칭 릴레이를 **RESET(해제)** → 이때 비로소 헹굼(1단계) 모드 활성화.
  - 즉 "건조·배출을 실제로 완료해야만 다음 세척이 가능"한 구조. 강제 전원 리셋·시간차 배출 등 비정상 조작으로는 우회 불가.
- **딜레이 타이머**: 투입구 마개가 열리면 카운터 시작(1분/2분), 모터 전원 차단 → 경과 후 재연결.

## 6. 테스트 / A/S 모드 (로직도 5p)

- **모터 개별 테스트**: "모터선택" 버튼 약 3초 누른 뒤 1회씩 누를 때마다 "1번 분쇄모터 / 2번 교반모터 …" 음성 안내 → 번호 선택 후 "정회전"·"역회전"으로 구동 확인 (설정된 회전값으로 동작).
- **BLDC 분쇄모터(200W) RPM 가변 설정**
  - "모터선택" 3초 → 모터 번호 선택 → 다시 "모터선택" 3초 → RPM 설정 모드 진입
  - "동작(수동동작)" 누름 시간으로 구간 회전 설정: **2초=10분 / 4초=60분 / 6초=90분 / 8초=105분 / 10초=120분 이내 구간**
  - 상·하 버튼 1회당 설정 RPM에서 **±10%** 조정 → "모터선택" 5초로 저장. (나머지 모터 RPM은 불변)
- 테스트 대상 모터 11종·센서류 목록 정의 (5p 참조).

## 7. 검토 의견 — 확인·보완 필요 사항

문서 간 상충되거나 개발 착수 전 명확화가 필요한 항목.

### 7.1 문서 간 수치 상충

| 항목 | 로직도 PDF | 사양서 PDF | 초안 docx | 확인 필요 |
|------|-----------|-----------|-----------|-----------|
| 히터 출력 | 150W×2 + **300W×2** (2p) | 150W×2 + **250W×2** | 300W×2 / DV2 900W | 250W vs 300W **불일치** |
| 바이메탈 개수 | — | **7개**(200off×3, 80off×1, 80on×2, 50on×1) | **6개** | 개수 확정 필요 |
| 홀센서 개수 | 조작 5 + 개별 3 = **8** | 조작 5 + 개별 4 = **9**(승강부 포함) | 8개 | 승강부 위치센서 포함 여부 |
| 교반모터 정격속도 | RPM 40 | 44 → **40 변경예정** | — | 40 확정 시 반영 |

### 7.2 로직상 모호/미확정 (원본에 "?" 표기된 항목)

1. **배출 시작 처리 횟수 기준** — 4p에 "6번째면 배출 시작? 이상일 경우…"로 **6회/7회 기준이 물음표**. 4단계 진입도 "6회 종료 후 7회째"로 되어 있어 **카운트 기준(6 vs 7) 정의 필요**.
2. **급수 정지 타이밍** — "센서 감지 시작 ~ ?초 후 정지"에서 지연 시간 미확정.
3. **RPM/회전시간/정·역 방향** — 대부분 "가변 가능"으로만 명시, 양산 기본값 미확정. (멤브레인/원격 버튼으로 변경 가능하게 설계)
4. **분쇄 반복 횟수** — 초안 "탁탁 쳐주듯이 10회?" 물음표.
5. **2시간 총 공정 중 마지막 30분(15분 RPM 상향)** — 테스트 조건으로만 표기, 확정 필요.
6. **미확정 부품** — 히터 온도센서(써미스터) 모델, 바이메탈·릴레이·리미트스위치·타이머 모델, 공기흡입 스테핑모터(Ø35), 배수부 급수라인 수위센서 등 **모델 미확정** 다수.

### 7.3 안전/사용성 관점 검토 포인트

- **살균세척 물의 수거통 배출**: 뜨거운(냉각 후) 물을 수거통으로 버리는 흐름 → 사용자 화상/누수 안전 및 수거통 방수 용량 확인 필요.
- **음성 안내 미응답 시 처리**: 수거통 미비움 시 "10분 후 교반 정지·대기" 후의 **복구 절차(재개 조건)** 명확화 필요.
- **투입구 오조작(무의식 개방)**: 대기 중 마개 개방 → 비상음 + "동작 위치 복귀" 안내 2회 후 재삽입(홀센서) 시 배출 절차 재개 — **상태 머신 정의** 필요.
- **불법배출 방지 회로 vs MCU 제어 경계**: 바이메탈·래칭 릴레이(하드웨어)와 MCU 제어(소프트웨어)의 **책임 분담**을 명확히 해야 함. (MCU가 죽어도 하드웨어 차단이 유지되는지 검증)

### 7.4 초안(docx) 해석 상 주의

초안은 원본 PDF를 개발자가 **자의적으로 재해석한 메모**로, 원본과 다음 차이가 있어 원본 로직도를 기준으로 삼는 것을 권장:
- 히터 4개/커넥터 구성, "DV2 900W" 등 초안에만 등장하는 전력 구성.
- 1단계 순서 서술이 로직도(모음)와 세부 순서가 다름(초안은 헹굼→배수→급수 순).
- 온도/시간 수치가 로직도의 시간대별 프로파일보다 단순화(“1시간에 170도”)되어 있음.

## 8. 요약

- 4단계(모음 → 동작 → 자가세척 → 살균세척) 자동 공정 + **하드웨어 기반 불법배출 방지**가 제품의 두 축.
- 모터 7종·홀센서 8~9개·바이메탈 6~7개·히터 4개(220V)·SMPS 24V로 구성.
- **온도-시간 프로파일, RPM/회전 파라미터, 부품 모델**은 다수 "가변/미확정" 상태 → 양산 전 **기본값 확정 및 테스트 검증** 필요.
- 개발 기준 문서는 **로직도 PDF를 마스터**로, 사양서 PDF를 부품 근거로, 초안 docx는 참고용으로 취급 권장.
